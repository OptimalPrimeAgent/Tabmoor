Privatlivspolitik for Tabmoor

Senest opdateret: 2. november 2026. Gælder for browserudvidelsen Tabmoor til Chrome og Firefox.

Udgiver: Patrick Thams-Dimon. Kontakt: thamsdimon@gmail.com

Kort sagt: Tabmoor gemmer dine faner lokalt på din egen enhed. Vi modtager ingen data, sender intet over nettet og bruger ingen sporing.

1. Hvilke data udvidelsen håndterer

For at kunne gemme og gendanne sessioner læser Tabmoor adresse (URL), sidetitel, fastgjort-status og fanegruppe (navn og farve) for fanerne i dine almindelige vinduer, samt vinduernes størrelse og placering. Det er browseraktivitet (webhistorik) i Chrome Web Stores forstand. Private vinduer læses aldrig.

2. Hvor data opbevares

Sessioner, backups og indstillinger gemmes kun i browserens lokale lager (storage.local og storage.session) på din enhed. Data sendes ikke til udgiveren eller nogen anden. Udvidelsen har ingen server og foretager ingen netværkskald.

3. Formål

Data bruges udelukkende til udvidelsens ene formål: at gemme, sikkerhedskopiere og gendanne dine browserfaner, når du beder om det, eller automatisk som backup.

4. Deling, salg og annoncer

Ingen data deles, sælges eller overføres. Der er ingen annoncer, ingen analyseværktøjer, ingen cookies og ingen konto.

5. Opbevaringstid og sletning

Gemte sessioner bliver, indtil du sletter dem. Automatiske backups roterer, så kun de seneste 10 beholdes. Afinstallerer du udvidelsen, sletter browseren alle dens data.

6. Eksport

Hvis du selv eksporterer, gemmes en JSON-fil på din computer. Du bestemmer, hvad der sker med filen.

7. Tilladelser

  • tabs: læse adresser og titler på åbne faner og åbne dem igen.
  • tabGroups: gemme og genskabe fanegruppers navn og farve.
  • storage, unlimitedStorage: gemme sessioner og backups lokalt.
  • alarms: planlægge den automatiske backup.

8. Chrome Web Store: begrænset brug

Tabmoors brug af oplysninger følger Chrome Web Stores politik for brugerdata (Chrome Web Store User Data Policy), herunder kravene om begrænset brug (Limited Use).

9. Ændringer

Ændres politikken, opdateres datoen øverst. Hvis en fremtidig betalt version kræver behandling af data (fx betaling via en betalingsudbyder), beskrives det her, før den lanceres.

10. Kontakt og dine rettigheder

Spørgsmål kan sendes til thamsdimon@gmail.com. Da udgiveren ikke modtager eller opbevarer dine data, ligger alle data hos dig og kan slettes direkte i udvidelsen. Du kan klage til Datatilsynet (datatilsynet.dk).

Tabmoor Privacy Policy

Last updated: November 2, 2026. Applies to the Tabmoor browser extension for Chrome and Firefox.

Publisher: Patrick Thams-Dimon. Contact: thamsdimon@gmail.com

In short: Tabmoor stores your tabs locally on your own device. We receive no data, nothing is sent over the network and there is no tracking.

1. Data the extension handles

To save and restore sessions, Tabmoor reads the URL, page title, pinned state and tab group (name and colour) of tabs in your normal windows, plus window size and position. This is web browsing activity (web history) as defined by the Chrome Web Store. Private windows are never read.

2. Where data is stored

Sessions, backups and settings are stored only in the browser's local storage (storage.local and storage.session) on your device. Data is never sent to the publisher or anyone else. The extension has no server and makes no network requests.

3. Purpose

Data is used only for the extension's single purpose: saving, backing up and restoring your browser tabs, on request or automatically as a backup.

4. Sharing, sale and ads

No data is shared, sold or transferred. There are no ads, no analytics, no cookies and no account.

5. Retention and deletion

Saved sessions are kept until you delete them. Automatic backups rotate, keeping only the latest 10. Uninstalling the extension makes the browser delete all of its data.

6. Export

If you export, a JSON file is saved on your computer and stays under your control.

7. Permissions

  • tabs: read URLs and titles of open tabs and reopen them.
  • tabGroups: save and recreate tab group names and colours.
  • storage, unlimitedStorage: store sessions and backups locally.
  • alarms: schedule the automatic backup.

8. Chrome Web Store Limited Use

The use of information received by Tabmoor adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

9. Changes

Changes update the date above. If a future paid version needs any data processing (for example payment through a payment provider), it will be described here before launch.

10. Contact and your rights

Questions: thamsdimon@gmail.com. Because the publisher never receives or stores your data, all data stays with you and can be deleted directly in the extension. You may lodge a complaint with your data protection authority (in Denmark: Datatilsynet).
