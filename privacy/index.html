Privatlivspolitik for Tabmoor

Senest opdateret: 5. november 2026. Udkast, ikke godkendt til offentliggørelse. Gælder for browserudvidelsen Tabmoor til Chrome, Microsoft Edge og Firefox.

Sælger: Patrick, bosat i Danmark. Der vises ingen privatadresse. Kontakt: ptd.fullstack@gmail.com

Kort sagt: Tabmoor gemmer dine faner lokalt på din egen enhed. Fanedata forlader ikke browseren. Betaling klares af Stripe. Oplåsning sender kun en kode og et tilfældigt installations-id til en Cloudflare-server, og kun når du selv beder om det. Ingen sporing.

1. Hvilke data udvidelsen håndterer

For at kunne gemme og gendanne sessioner læser Tabmoor adresse (URL), sidetitel, fastgjort-status og fanegruppe (navn og farve) for fanerne i dine almindelige vinduer, samt vinduernes størrelse og placering. Det er browseraktivitet (webhistorik) i Chrome Web Stores forstand. Private vinduer læses aldrig.

2. Hvor data opbevares

Sessioner, backups og indstillinger gemmes kun i browserens lokale lager (storage.local og storage.session) på din enhed. Fanedata sendes ikke til udgiveren. Udvidelsen har ingen egen server til faner. De eneste netværkskald fra udvidelsen er valgfrie og sker kun, når du låser Pro op eller deaktiverer den, som beskrevet i afsnit 3. Køb åbner Stripes side i en fane. Der er ingen analyse og ingen andre netværkskald. Der er ingen løbende kontakt med serveren, efter at Pro er låst op.

3. Pro, Stripe og Cloudflare

Køb af Tabmoor Pro sker hos Stripe (via Link). Stripe er merchant of record og behandler betaling, navn, e-mail og faktureringsoplysninger under sin egen privatlivspolitik. Tabmoor ser ikke kortoplysninger. Prisen er 99 kr. inkl. moms, et engangskøb, livstid, op til 3 browsere. Sælger er Patrick, bosat i Danmark. Der vises ingen privatadresse.

Når du har betalt, viser betalingssiden en oplåsningskode. I udvidelsen sender du koden sammen med et tilfældigt installations-id (et UUID, der oprettes én gang på denne browser) til oplåsningsserveren på Cloudflare, https://tabmoor-unlock.tabmoor.workers.dev. Det sker kun, når du låser Pro op eller deaktiverer den på denne browser.

Serveren gemmer kun oplåsningskoden, Stripe Checkout Session-id, tilfældige installations-id'er med tidsstempler, og ved mislykkede forsøg IP-adressen i en tæller, der sletter sig selv efter ca. 1 time. Cloudflare behandler som vært forespørgselsdata såsom IP-adresse. Der gemmes ikke navn, e-mail eller betalingsdata hos os.

Svaret er et signeret token. Udvidelsen tjekker signaturen lokalt. Pro slås kun til, hvis signaturen er gyldig, tokenet er til Pro, og det hører til denne browsers installations-id. Koden og tokenet gemmes lokalt. Fanedata forlader ikke browseren.

Deaktivér på denne browser sender koden og installations-id'et én gang, så pladsen frigives, og sletter derefter koden og tokenet på denne browser. Afinstallation sletter også browserens lokale data.

Formål og grundlag: at opfylde købet. Sletning: deaktivér i udvidelsen, eller afinstallér den.

4. Formål

Fanedata bruges udelukkende til udvidelsens ene formål: at gemme, sikkerhedskopiere og gendanne dine browserfaner, når du beder om det, eller automatisk som backup. Oplåsningskoden bruges kun til at låse Pro op på den browser, hvor du indtaster den.

5. Deling, salg og annoncer

Fanedata deles ikke, sælges ikke og overføres ikke. Der er ingen annoncer, ingen analyseværktøjer, ingen cookies og ingen konto. Den eneste overførsel fra udvidelsen er den valgfrie oplåsning eller deaktivering i afsnit 3, og den indeholder ikke fanedata. Betaling sker hos Stripe, ikke i udvidelsen.

6. Opbevaringstid og sletning

Gemte sessioner bliver, indtil du sletter dem. I gratisversionen roterer automatiske backups, så kun de seneste 10 beholdes. Med Pro beholdes de seneste 50, og derudover én backup pr. dag i 30 dage. Afinstallerer du udvidelsen, sletter browseren alle dens data, inklusive en eventuel oplåsningskode og token. Fejlede oplåsningsforsøg på serveren sletter deres IP-tæller efter ca. 1 time.

7. Eksport

Hvis du selv eksporterer, gemmes en JSON-fil på din computer. Du bestemmer, hvad der sker med filen. Oplåsningskoden og tokenet er ikke en del af eksporten.

8. Tilladelser

  • tabs: læse adresser og titler på åbne faner og åbne dem igen.
  • tabGroups: gemme og genskabe fanegruppers navn og farve.
  • storage, unlimitedStorage: gemme sessioner og backups lokalt.
  • alarms: planlægge den automatiske backup.
  • Ingen værtstilladelser. Oplåsning er et almindeligt CORS-kald til oplåsningsserveren, kun når du selv låser op eller deaktiverer.

9. Chrome Web Store: begrænset brug

Tabmoors brug af oplysninger følger Chrome Web Stores politik for brugerdata (Chrome Web Store User Data Policy), herunder kravene om begrænset brug (Limited Use).

10. Ændringer

11. Kontakt og dine rettigheder

Spørgsmål om Tabmoor: ptd.fullstack@gmail.com. Fanedata ligger hos dig og kan slettes direkte i udvidelsen. Du kan klage til Datatilsynet (datatilsynet.dk).

Tabmoor Privacy Policy

Last updated: November 5, 2026. Draft, not approved for publication. Applies to the Tabmoor browser extension for Chrome, Microsoft Edge and Firefox.

Seller: Patrick, based in Denmark. No home address is published. Contact: ptd.fullstack@gmail.com

In short: Tabmoor stores your tabs locally on your own device. Tab data does not leave the browser. Stripe handles payment. Unlocking sends only a code and a random install id to a Cloudflare server, and only when you ask. There is no tracking.

1. Data the extension handles

To save and restore sessions, Tabmoor reads the URL, page title, pinned state and tab group (name and colour) of tabs in your normal windows, plus window size and position. This is web browsing activity (web history) as defined by the Chrome Web Store. Private windows are never read.

2. Where data is stored

Sessions, backups and settings are stored only in the browser's local storage (storage.local and storage.session) on your device. Tab data is never sent to the publisher. The extension has no server of its own for tabs. The only network requests from the extension are optional and happen only when you unlock Pro or deactivate it, as described in section 3. Buying opens Stripe's page in a tab. There is no analytics and no other network request. There is no periodic call after Pro is unlocked.

3. Pro, Stripe and Cloudflare

Tabmoor Pro is bought from Stripe (via Link). Stripe is the merchant of record and processes payment, name, email and billing data under its own privacy policy. Tabmoor does not see card details. The price is 99 DKK incl. VAT, one-time, lifetime, up to 3 browsers. The seller is Patrick, based in Denmark. No home address is published.

After you pay, the checkout page shows an unlock code. In the extension you send that code together with a random install id (a UUID created once on this browser) to the unlock server on Cloudflare, https://tabmoor-unlock.tabmoor.workers.dev. That happens only when you unlock Pro or deactivate it on this browser.

The server stores only the unlock code, the Stripe Checkout Session id, random install ids with timestamps, and, for failed attempts, the IP address in a counter that deletes itself after about 1 hour. Cloudflare, as the host, processes request data such as the IP address. We do not store name, email or payment data.

The response is a signed token. The extension checks the signature locally. Pro turns on only if the signature is valid, the token is for Pro, and it belongs to this browser's install id. The code and the token are stored locally. Tab data does not leave the browser.

Deactivate on this browser sends the code and the install id once, so the slot is freed, and then deletes the code and the token on this browser. Uninstalling also deletes the browser's local data.

Purpose and basis: performing the purchase. Deletion: deactivate in the extension, or uninstall it.

4. Purpose

Tab data is used only for the extension's single purpose: saving, backing up and restoring your browser tabs, on request or automatically as a backup. The unlock code is used only to unlock Pro on the browser where you enter it.

5. Sharing, sale and ads

Tab data is not shared, sold or transferred. There are no ads, no analytics, no cookies and no account. The only transfer from the extension is the optional unlock or deactivation in section 3, and it does not include tab data. Payment happens at Stripe, not in the extension.

6. Retention and deletion

Saved sessions are kept until you delete them. On the free version, automatic backups rotate so only the latest 10 are kept. Pro keeps the latest 50, plus one backup per day for 30 days. Uninstalling the extension makes the browser delete all of its data, including an unlock code and token if they were stored. Failed unlock attempts on the server drop their IP counter after about 1 hour.

7. Export

If you export, a JSON file is saved on your computer and stays under your control. The unlock code and the token are not part of the export.

8. Permissions

  • tabs: read URLs and titles of open tabs and reopen them.
  • tabGroups: save and recreate tab group names and colours.
  • storage, unlimitedStorage: store sessions and backups locally.
  • alarms: schedule the automatic backup.
  • No host permissions. Unlocking is an ordinary CORS call to the unlock server, only when you unlock or deactivate.

9. Chrome Web Store Limited Use

The use of information received by Tabmoor adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.
