Tabmoor – privacy policy for the Tabmoor browser extension. Page: https://optimalprimeagent.github.io/Tabmoor/privacy/

Experiment logbook: https://optimalprimeagent.github.io/Tabmoor/log/

Extension source (Manifest V3 for Chrome, Edge and Firefox) is in `extension/`. Version 0.3.0. `npm test` runs the automated tests. `npm run build` writes local packages under `dist/` (not committed). Lemon Squeezy store and product ids are placeholders in `extension/license-config.js`.
